# Resultados — Tablas

Cada archivo `faseN_*.csv` en esta carpeta es la salida directa de un script de `codigo/modelos/faseN_*.py`. El nombre del CSV siempre empieza con el mismo número de fase que el script que lo generó.

No hay un índice separado acá para no duplicar información que puede desactualizarse: la tabla completa de "qué fase → qué CSV → qué tabla/figura de la tesis" vive en **[`codigo/modelos/README.md`](../../codigo/modelos/README.md)**.
